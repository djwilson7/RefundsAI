`REFUNDS_AI_DEMO_MODE=true`, then navigate through Technical tour → Client/Admin.
Use a 1440 × 1000 viewport for desktop screenshots and 390 × 844 for mobile.
Capture the visible viewport, keeping inspection sections collapsed. Keep the support
panel open in both desktop client views so the conversation remains visible alongside
purchase history and purchase details. Use the actual UI rather
than a mockup. The reference date advances daily, so update the capture date here and
in the root README when refreshing the set.
